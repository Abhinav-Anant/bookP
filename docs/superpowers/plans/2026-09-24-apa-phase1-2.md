# APA Phase 1 + 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Liseur fork into **APA**, an Android app backed by a
Supabase cloud library. When a book is published in Supabase it appears
in the app, can be read offline, and the reading position syncs across
devices.

**Architecture:** The Supabase backend exposes one Edge Function, `api`.
It speaks the small subset of the **Komga REST API** that Liseur's
existing Komga client uses, plus a few `/apa/*` routes for discovery and
the wishlist. The app connects to it as a Komga server, authenticated
with a per-device API key. The key is minted after an email-OTP or
Google sign-in. As a result, Liseur's tested catalogue, download, sync
and conflict code is reused unchanged, and each device has a key an
admin can revoke.

**Tech Stack:** Kotlin, Jetpack Compose, Readium 3.3, Room, OkHttp and
`org.json` (already in the project), Supabase (Postgres, Auth, Storage,
Edge Functions in Deno/TypeScript), and Android Credential Manager for
Google sign-in.

**Spec:** `docs/superpowers/specs/2026-09-24-apa-phase1-2-design.md`

**Deviation from spec (implementation detail, same behaviour):** the
spec named `supabase-kt`. This plan uses plain OkHttp calls against
Supabase Auth plus a Komga-compatible Edge Function. That adds no new
Kotlin serialisation stack and reuses about 2,000 lines of existing
Komga sync code.

- Download URLs are never public. File routes check the device key and the entitlement on every request.
- Do not commit without the user's approval. The repository's `AGENTS.md` also forbids AI co-author trailers.

```sql
create table profiles (
  id uuid primary key references auth.users on delete cascade,

create table authors (id uuid primary key default gen_random_uuid(), name text not null, bio text, photo_url text);
```

| Route | Auth | Answer |
|---|---|---|
| `POST /apa/devices` | `Authorization: Bearer <user JWT>`, body `{name}` | `{key}` (32-byte random, base64url; only its sha256 is stored) |
| `GET /api/v2/users/me` | `X-API-Key` | `{id, email, roles:["FILE_DOWNLOAD"]}` |
| `POST /api/v1/books/list?page&size` | `X-API-Key` | Komga page `{content:[…], last}` of the user's **library**: entitled books ∪ `library_items`, excluding wishlist-only rows. Body `fullTextSearch` filters by title. |
| `GET /api/v1/books/{id}` | `X-API-Key` | one Komga book |
| `GET /api/v1/books/{id}/thumbnail` | none | 302 to the public cover URL |
| `GET /api/v1/books/{id}/file?format=` | `X-API-Key` | Only if the user is entitled (free books grant it automatically). 302 to a 300-second signed Storage URL. Otherwise 403. |
| `GET/PUT /api/v1/books/{id}/progression` | `X-API-Key` | `{locator, modified, device}` from `reading_state`. PUT with an older `modified` answers 409. |
| `PATCH/DELETE /api/v1/books/{id}/read-progress` | `X-API-Key` | sets `completed`, or deletes the row |
| `GET /api/v1/series/{id}` | `X-API-Key` | 404 (APA has no series yet; the client tolerates this) |
| `GET /apa/home` | `X-API-Key` | `{rows:[{key,title,books:[card…]}]}`, where `key` is one of `featured`, `editors_pick`, `new`, `trending`, `free`, `wishlist` |
| `GET /apa/books/{id}` | `X-API-Key` | full detail plus `inLibrary`, `wishlist`, `favorite`, `formats`, `moreByAuthor` |
| `PUT /apa/library/{id}` | `X-API-Key` | body `{wishlist?, favorite?, add?}`. `add:true` on a free book upserts the entitlement; on a paid book it answers 402. |
| `GET /apa/search?q=` | `X-API-Key` | cards matching `search @@ plainto_tsquery` |

```ts
export type BookRow = {
  id: string; title: string; author_name: string | null; pages: number | null;
  updated_at: string; size_bytes: number | null; format: string | null;
  reading_state?: { completed: boolean; updated_at: string; device_id: string | null } | null;
};

const PROFILE: Record<string, string> = { epub: "EPUB", pdf: "PDF", cbz: "DIVINA" };

export function toKomgaBook(r: BookRow) {
  return {
    id: r.id, name: r.title, oneshot: true, seriesId: null, seriesTitle: null,
    sizeBytes: r.size_bytes ?? 0, lastModified: r.updated_at,
    metadata: { title: r.title, authors: r.author_name ? [{ name: r.author_name, role: "writer" }] : [] },
    media: { pagesCount: r.pages ?? 0, mediaProfile: PROFILE[r.format ?? "epub"] ?? "EPUB", status: "READY" },
    readProgress: r.reading_state
      ? { page: 0, completed: r.reading_state.completed, readDate: r.reading_state.updated_at, deviceId: r.reading_state.device_id }
      : null,
  };
}

export function toKomgaPage(rows: BookRow[], size: number) {
  return { content: rows.map(toKomgaBook), last: rows.length < size };
}
```

- [ ] **Step 5: Implement the `index.ts` router.** Use `Deno.serve`, and `createClient(SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY)`, which is the service role because the function enforces ownership itself.
  - Strip the `/api` function prefix: `new URL(req.url).pathname.replace(/^\/api/, "")`.
  - Authenticate: `const { data: uid } = await db.rpc("device_user", { key: req.headers.get("x-api-key") })`. If it's null, answer 401 (except for the thumbnail route and `POST /apa/devices`).
  - `POST /apa/devices` authenticates with `db.auth.getUser(bearer)`. It generates `crypto.getRandomValues(new Uint8Array(32))`, base64url-encodes it, inserts `key_hash = sha256 hex` and answers `{key}`.
  - Library listing query: `books` joined with `authors` and the first `book_files` row, filtered to `id in (entitlements for uid) or id in (library_items for uid where not wishlist)` with status approved, ordered by title, and paginated with `range(page*size, page*size+size-1)`. Attach `reading_state` for uid.
  - File route: if the book is free, upsert `entitlements(uid, id, 'free')`; if there's still no entitlement, answer 403. Otherwise `db.storage.from("books").createSignedUrl(path, 300)` and `Response.redirect(url, 302)`.

  - Home rows:
    - `featured` and `editors_pick`: filter on the flags
    - `new`: order by `published_on desc`
    - `free`: `is_free`
    - `trending`: book_ids with the most `reading_state` rows updated in the last 7 days, via an `rpc` or a `select book_id, count(*) … group by`, run as the service role
    - `wishlist`: `library_items.wishlist` for uid
  - Card shape: `{id,title,author,coverUrl,isFree,priceInr,language,genres}`, where `coverUrl` = `${SUPABASE_URL}/storage/v1/object/public/covers/${cover_path}`.
  - Every error goes out as JSON `{error}` with a correct status. Never leak the storage path.

```kotlin
class ApaAuthClient(supabaseUrl: String, anonKey: String, http: OkHttpClient) {
    suspend fun sendEmailOtp(email: String): Result<Unit>                     // POST /auth/v1/otp {email, create_user:true}
    suspend fun verifyEmailOtp(email: String, code: String): Result<String>    // POST /auth/v1/verify {type:"email",email,token} → access_token
    suspend fun signInWithPassword(email: String, password: String): Result<String> // POST /auth/v1/token?grant_type=password
    suspend fun signInWithGoogle(idToken: String): Result<String>             // POST /auth/v1/token?grant_type=id_token {provider:"google", id_token}
    suspend fun mintDeviceKey(accessToken: String, deviceName: String): Result<String> // POST {supabaseUrl}/functions/v1/api/apa/devices → key
}
```

**Files:**

- Modify: the download pipeline (`data/calibre/BookDownloader.kt`), which encrypts each APA book as it is written.
- Modify: `AppContainer.kt`'s `AssetRetriever`/`PublicationOpener`. Encrypted books are served to Readium through a seekable decrypting channel (`StreamingAead.newSeekableDecryptingChannel`) wrapped as a Readium `Resource`, so nothing is ever decrypted to disk.
- Modify: `strings.xml`. Label APA books "Save for offline" and "Remove offline copy" instead of "Download"/"Delete".
- Test: `BookVaultTest`, a Robolectric round-trip that encrypts, then does a seek-and-read of a byte range that matches the plaintext. It also checks that the ciphertext differs from the plaintext and that it doesn't contain the `mimetype` EPUB marker.
